# npb-data-analysis
# NPBにおける試合展開と観客動員の関係分析データ

# 1.データ出典
NPB公式サイト（https://npb.jp)

# 2.内容概要
NPB公式サイトから、2022年の公式戦データをスクレイピングにより収集した。
収集したデータには、単なる勝敗だけでなく、試合の展開を表す詳細指標を含む。

　●取得項目：年度,日付,曜日,週末/祝日,球場,試合時間,ホーム球団,ビジター球団,ホーム得点,ビジター得点,ホーム安打,ビジター安打,ホーム失策,ビジター失策,ホームラン_ホーム,ホームラン_ビジター,ホームラン合計,HR詳細_ホーム,HR詳細_ビジター,ホーム勝利,得点差,逆転あり,サヨナラ,延長戦,リード変化回数,最終得点イニング,イニング別得点,勝利投手,敗戦投手,セーブ投手,URL

# 3.分析の目的・期待
プロ野球において、「どのような試合が次回の観客動員を増やすのか」を定量的に分析する

 
 ●試合展開と次の試合の観客動員数の関係を分析する。

# 4.収集方法
Python(Requests,BeautifulSoup)を用いたWebスクレイピング。
